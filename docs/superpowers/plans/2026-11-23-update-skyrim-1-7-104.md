# Skyrim AE 1.7.104 Compatibility Update Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Update the Auto-Shot / Click-Casting SKSE64 plugin to support Skyrim SE/AE runtime 1.7.104 (`1.7.104.0`) with Address Library Format 5 support while maintaining backwards compatibility with 1.5.97 and 1.6.x (1.6.640 / 1.6.1170).

**Architecture:** Upgrades CommonLibSSE-NG to the active multi-runtime branch with Address Library Format 5 and `kAE1799ShiftBytes` runtime layout compatibility. Adds a local overlay port or updated vcpkg registry mapping for `alandtse/CommonLibSSE-NG`, configures automated GitHub Actions CI for MSVC C++23 Windows builds, and bumps version numbers across manifests and documentation.

**Tech Stack:** C++23, CMake 3.21+, MSVC v143, vcpkg, CommonLibSSE-NG (`alandtse/CommonLibSSE-NG`), SimpleIni, Address Library v13+, GitHub Actions.

**Spec:** Direct update of `Machanu/skyrim-click-casting` from version 2.0.0 to 2.1.0 targeting Skyrim AE 1.7.104.

---

## Global Constraints

- Must retain multi-target runtime compatibility: SE 1.5.97, AE 1.6.640, AE 1.6.1170, and AE 1.7.104 supported by a single DLL output.
- No regression in core click-casting or bow auto-shot behavior.
- Do not introduce hardcoded byte offsets; rely strictly on CommonLibSSE-NG's versioned runtime accessors (`GetActorRuntimeData()`, `AsActorState()`).
- Keep MCM layout and Papyrus scripts backwards compatible.

## Review Focus

1. **Address Library Format 5 parsing**: The binary must open and load `versionlib-1-7-104-0.bin` without triggering `Unsupported address library format: 5`.
2. **Actor Update Hook (`VTABLE_PlayerCharacter[0]` slot `0xAD`)**: Must safely intercept `PlayerCharacter::Update` on 1.7.104 without offset collision.
3. **Actor Data Shifts**: `pc->GetMagicCaster(...)` and `pc->AsActorState()->GetAttackState()` must resolve correctly despite the 0x8 byte base class insertion in 1.7.99+.
4. **Log Path Resolution**: Verified to use Win32 `SHGetKnownFolderPath` so it remains immune to Bethesda's `Skyrim.INI` path bug.
5. **Clean CI Build**: The repository must compile cleanly in an automated GitHub Actions runner producing `AutoShotClickCasting.dll`.
